TOKEN INFORMATION

Input tokens:
Text, images, audio, or other supported content sent to a model.

Output tokens:
Content generated by the model. Some models also count thinking tokens.

Context window:
The maximum amount of input and output a model can handle in a request. It is different from the price per million tokens.

Important:
Not every model has the same context window or output limit. Confirm the exact limits for each model on the official documentation.
